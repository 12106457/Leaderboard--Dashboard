# Leaderboard UI - React.js + Tailwind CSS + shadcn/ui

## Objective
Build a pixel-perfect leaderboard UI in **React.js** using **Tailwind CSS** and **shadcn/ui** components. The design must match the Figma screens exactly, including layout, spacing, colors, typography, responsiveness, and all component states (hover, focus, active, disabled).  

Dynamic behavior such as pagination, dynamic columns, and icon rendering based on backend data should be implemented. Accessibility and consistent theming are also required.

---

## Tech Stack
- **Frontend:** React.js  
- **Styling:** Tailwind CSS  
- **UI Components:** shadcn/ui  
- **Icons:** Phosphor Icons  

---

## Features

### Leaderboard View
- Fully replicates the Figma design for leaderboard screen.
- Table has a **fixed height** with scrollable content.
- **User’s fixed row** scrolls horizontally in sync with the main table.
- **Dynamic columns** support different subject configurations (PCM or custom subjects).
- Proper **pagination** implemented.
- Fully **responsive** across screen sizes.

### Dynamic Behavior
- Icon names returned from the backend are mapped dynamically to Phosphor icons.
- Supports multiple themes and consistent color variables.
- All component states handled (hover, focus, active, disabled).
